## 2024-05-24 - Interactive Empty States & Tooltips
**Learning:** Adding empty states that don't just say "empty" but guide the user ("Start a task to gather resources"), coupled with detailed tooltips for resource requirements and yields, significantly reduces confusion in resource-management interfaces without needing complex tutorials.
**Action:** Always check if a list or inventory can be empty on load, and proactively add a descriptive placeholder message. Default button tooltips should synthesize key backend data (costs/yields) for the user.
